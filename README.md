## About LabSim

**LabSim** is an interactive, web-based engineering platform designed to make electrical engineering experiments more accessible and engaging.

Students can explore virtual circuits, visualize electrical signals, experiment with logic gates, and calculate important electrical parameters through interactive simulations and engineering calculators.

## Features

### Interactive Simulations

- **Circuit Simulator** — Build circuits using drag-and-drop components and visualize circuit behavior.
- **Solar & Battery Backup Simulator** — Explore power generation and backup performance under different conditions.
- **Oscilloscope Simulator** — Visualize electrical signals and understand waveforms.
- **Logic Gate Simulator** — Explore digital logic operations and logic gates.

### Engineering Calculators

- Resistor Color Code & SMD Calculator
- Capacitor Code Calculator
- Wire Gauge & Cable Size Calculator
- Electrical Calculator for Voltage, Current, Resistance, and Power
- Solar Panel Calculator
- Battery Backup Calculator

### Electrical Engineer's Toolbox

- Unit conversion utilities
- Electrical safety guidelines
- Troubleshooting assistance
- Quick engineering references

### User Experience

- Clean and intuitive interface
- Dark and light theme support
- Responsive design
- Interactive tools for students and engineering enthusiasts

## Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Routing:** React Router

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd labsumulation_hack
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal.
